# 企微 Bot 命令列表

> SRE Copilot 企业微信 Bot 支持的所有命令

## 📋 命令概览

### 基础命令

| 命令 | 别名 | 说明 |
|------|------|------|
| `help` | `帮助` | 显示所有可用命令 |
| `ping` | - | 测试连接状态 |

### 系统信息

| 命令 | 别名 | 说明 |
|------|------|------|
| `status` | `状态` | 查看系统运行状态 |
| `config` | `配置` | 查看系统配置（隐藏敏感信息）|
| `version` | `版本` | 查看系统版本信息 |
| `db` | `数据库` | 查看数据库连接状态 |
| `time` | `时间` | 查看当前服务器时间 |

### 角色与权限

| 命令 | 别名 | 说明 |
|------|------|------|
| `whoami` | `我是谁` | 查看个人信息和角色 |
| `tools` | `工具` / `我的工具` | 查看可用工具列表 |
| `roles` | `角色列表` | 查看所有系统角色 |

## 📖 命令详解

**示例**：
```

```

**返回**：
```

• help / 帮助 - 显示此帮助
• status / 状态 - 系统状态
• config / 配置 - 查看配置信息
• db / 数据库 - 数据库状态
• roles / 角色列表 - 所有角色
• tools / 工具 / 我的工具 - 查看可用工具
• whoami / 我是谁 - 查看个人信息
• time / 时间 - 当前时间
• version / 版本 - 系统版本
• ping - 测试连接

💬 直接发问题，我会用 AI 回答。
```

### 2. status / 状态

**功能**：查看系统运行状态

**返回信息**：
- 服务状态（运行中/停止）
- 运行时长（天/小时/分钟/秒）
- 数据库连接状态
- 环境（development/production）
- 版本号
- 端口号
- Node.js 版本
- 平台信息
- 当前时间

**示例**：
```
status
```

**返回**：
```
📊 **系统状态**

🟢 服务状态：运行中
🕐 运行时长：2天 5小时 30分钟
💾 数据库：✅ 已连接
🌍 环境：production
🔧 版本：v1.0.0
📡 端口：3000
🧠 Node.js：v18.x.x
💻 平台：linux x64

⏰ 当前时间：2026-02-07 10:30:45
```

## 💡 使用提示

### 1. 命令不区分大小写
```
status  = STATUS = Status  ✅
help    = HELP   = Help    ✅
```

### 2. 支持中文别名
```
help    = 帮助   ✅
status  = 状态   ✅
tools   = 工具   ✅
time    = 时间   ✅
```

### 3. 命令可以包含在句子中
```
"请帮我查看一下状态"        → 触发 status 命令
"我想看看我的工具有哪些"    → 触发 tools 命令
"帮助"                      → 触发 help 命令
```

### 4. 非命令消息会调用 AI
```
"今天天气怎么样？"          → AI 回答
"帮我写一段代码"            → AI 回答 + 可能调用工具
```

## 🔐 权限说明

### 所有用户可用
- `help` / `ping` / `time` / `version`

### 需要身份识别
- `whoami` - 显示当前用户信息
- `tools` - 显示当前用户可用工具（按角色过滤）

### 需要数据库连接
- `roles` - 查询角色列表
- `tools` - 查询工具权限（降级时显示所有工具）
- `whoami` - 查询用户角色（降级时只显示 userId）

### 管理员推荐
- `status` - 监控系统状态
- `config` - 检查配置
- `db` - 检查数据库连接
